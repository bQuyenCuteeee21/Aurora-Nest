# Bộ sơ đồ Aurora Nest

Các file `.puml` dùng PlantUML và có thể mở bằng PlantUML extension trong VS Code:

- `use-case.puml`: sơ đồ Use Case tổng quát.
- `use-case-details.puml`: hai nhóm Use Case chi tiết: Check-in và Check-out/thanh toán.
- `class-diagram.puml`: lớp domain, Singleton, Factory, Strategy, Repository và DI Container.
- `sequence-booking.puml`: trình tự đặt phòng, tính giảm giá, tạo cổng thanh toán và ghi dữ liệu Neon.
- `activity-booking.puml`: quy trình hoạt động đặt phòng và xác nhận tiền cọc.
- `component-diagram.puml`: kiến trúc thành phần của Aurora Nest.

Trong VS Code: cài extension `PlantUML`, mở file `.puml`, rồi chọn `Alt+D` để xem sơ đồ. Có thể xuất PNG/SVG từ cửa sổ preview.
